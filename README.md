# 🍏 HealthyBytes

**HealthyBytes** is a web application built with **Flask** that helps users explore a wide variety of recipes, organized by categories, while providing detailed **nutritional information** for each recipe. Stay healthy and informed while enjoying delicious meals!

---

## 🌟 Features

- Browse **recipes** across multiple categories (e.g., Breakfast, Lunch, Dinner, Dessert).  
- View **detailed nutritional information** for each recipe (calories, protein, carbs, fat, etc.).  
- Search recipes by name, ingredients, or category.  
- Responsive and clean user interface using **Bootstrap**.  
- Easy to extend with new recipes, categories, and nutritional data.

---

## 🛠 Tech Stack

- **Backend:** Python, Flask  
- **Frontend:** HTML, Bootstrap  
- **Database:** SQLite 
- **Containerization:** Docker (optional)  

---
🥗 Database Models

Category: Stores recipe categories (e.g., Breakfast, Snacks).

Recipe: Contains recipe details (name, description, category, ingredients, instructions).

NutritionInfo: Stores nutritional values linked to each recipe (calories, protein, carbs, fat, etc.).

🎨 Features in Action

Homepage: Browse categories and popular recipes.

Recipe Page: View ingredients, instructions, and nutritional information.

Search & Filter: Quickly find recipes based on preferences or dietary requirements.
